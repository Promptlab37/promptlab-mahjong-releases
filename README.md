# Promptlab Mahjong — vydání

Veřejný kanál aktualizací hry **Promptlab Mahjong**.

Je tu **jen hotové APK**, žádný zdrojový kód. Hra se sem ptá na novou verzi
anonymně, bez přihlášení a bez jakéhokoli přístupového klíče — proto může být
repozitář veřejný, aniž by to cokoli prozradilo.

## Instalace

1. Stáhni APK z [posledního vydání](../../releases/latest)
2. Telefon se zeptá, jestli povolit instalaci z tohoto zdroje — potvrď
3. Nainstaluj přes stávající verzi; rozehrané hry a postup zůstanou

## Aktualizace přímo ve hře

*Nastavení → Aktualizace → Zkontrolovat.* Hra se sem podívá i sama po
spuštění, nejvýš jednou denně, a ozve se jen tehdy, když je opravdu co stáhnout.
